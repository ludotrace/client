# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in LudoTrace Client, please report it privately rather than opening a public issue.

- **Email:** security@ludotrace.com
- **GitHub:** use [private security advisory reporting](https://github.com/ludotrace/client/security/advisories/new) for this repo

Please include:
- A description of the vulnerability and its potential impact
- Steps to reproduce (proof-of-concept code, if applicable)
- The affected version or commit

### Response time

We aim to acknowledge reports within **5 business days** and to provide a fix or mitigation plan within **30 days**, depending on severity.

### Scope

In scope:
- The LudoTrace Client daemon and its authentication, storage, and upload paths

Out of scope:
- Vulnerabilities in third-party dependencies (please report upstream)
- A formal bug bounty program
- Denial-of-service issues requiring unrealistic resource expenditure

## Disclosure

Please give us a reasonable opportunity to fix the issue before any public disclosure. We're happy to credit reporters in release notes if desired.
